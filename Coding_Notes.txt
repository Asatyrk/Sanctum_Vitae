To add new character (/other):
- Create new .json in characters (/other) folder with profile info
- Tags can be found in characters.js
- Add to index.json so it shows up in layout
- Banner is 600x200, Fullbody is 400x600

Image key:
Headshot = polaroid 
Avatar = circle image 
Banner = splash image 
Fullbody = body ref 
Decor = other splash images

Particle shapes:
- square
- circle
- rounded
- pill
- rectangle
- triangle
- sparkle
- hexagon
- star
- cross
- heart
- frame
- leaf
- bird
