To add new character (/other):
- Create new .json in characters (/other) folder with profile info (use base)
- Tags can be found in characters.js
- Add to index.json so it shows up in layout (inc. headshot)

Image key:
Headshot [1:1] = polaroid 
Avatar [1:1] = circle image 
Banner [3:1] = splash image 
Fullbody [2:1] = body ref 
Decor [~10:1] = other splash images

Particle shapes:
- square
- circle
- rounded
- pill
- rectangle
- triangle
- sparkle
- hexagon
- star
- cross
- heart
- frame
- leaf
- bird
