To add new:

Character:
- Create new .json in characters folder with profile info (use base)
- Tags can be found in characters.js
- Add to index.json so it shows up in layout (inc. headshot). 
- Try to keep index in alphabetical order (refer to google sheets, A-Z auto-sorts).

Stories:
- Create new .json in stories folder with story info (use base)
- Tags can be found in stories.js
- Add to index.json so it shows up in layout. 
- Try to keep index in alphabetical order (not as needed)
